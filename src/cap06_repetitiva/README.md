# Capítulo 6 - Estrutura repetitiva

Aulas 49 a 62. Estruturas de repetição para executar um trecho de código várias vezes: `while` (enquanto), `for` (para) e `do-while` (faça-enquanto). O capítulo também ensina a usar o debug da IDE para executar o programa passo a passo e o teste de mesa, que é simular manualmente a execução de um laço para entender o valor das variáveis a cada repetição
